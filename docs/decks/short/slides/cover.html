Hi, I’m [your name]. First, what Déjà Vu is not: it’s not another chatbot. It’s an infer-then-confirm, user-owned, bounded memory layer for everyday personal agents. It’s a memory layer that any personal agent can add, Muse, ChatGPT, Claude, or your own, so it remembers you the way a good assistant would. It learns short cards from your chats, uses only the ones that fit each request, checks with you once when a guess really matters, and lets short-term things go on their own date. Confirmed memory for any agent. The chat you’ll see in the demo is just a host to show it.
