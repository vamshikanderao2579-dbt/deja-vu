Here’s what made me build this. My agent’s memory file is empty. But a week later it still remembers my dinner spot. So there is a memory; I just can’t see it. That’s three problems. It’s invisible. It can’t be corrected, so old guesses stick around. And it’s expensive, because the agent keeps re-deriving who I am from years of chat.
