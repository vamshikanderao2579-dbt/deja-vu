Don’t present this slide as the demo: switch to the real screen, a fresh tab on the demo link. The tour runs the same question twice. First as today’s agents do it: a hidden summary of Alex, about 450 tokens with every message, that Alex never sees. Then Déjà Vu reads the same chats and writes short cards, each a guess. In a new chat, the same question uses about 150 tokens of cards, and one line checks the guess the pick depends on. Alex taps ✕, says what changed in one tap, and the pick updates; nothing is booked without Alex. A small question gets no check, so it doesn’t nag. Then Memory: flip a card to see where it came from, swipe two left and two right, and say what’s true now: both cards update, confirmed. If the demo can’t run, this slide tells the story on its own.
