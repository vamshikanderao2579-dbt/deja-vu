— How it’s built

Plain Node, zero dependencies. Built on Meta’s models.

STAGED BUILD

Guard → Muse Spark writes → self-review → Muse Wonder grades → contract

Secrets and steering removed first. Wonder checks each card against the chat it cites. A malformed build reruns; every stage is checkpointed.

BOUNDED MEMORY

10 topics × 8 cards × 14 words

Each request picks the cards that fit and how high the stakes are. A topic cache makes a redo instant. Short-term cards carry an end date.

DON’T-NAG RULE, IN CODE

Asks only when a key guess meets high stakes

A guess that changed or is a year old, a booking-level request, nothing asked in this chat yet. Never style, agent or private cards.

ANY AGENT, OVER HTTP

recall · remember · confirm

Muse Spark answers, Muse Wonder grades, Muse Voice Transcribe takes spoken replies. 65 tests, a 14-person eval, live on Modal.

For anyone who wants the depth. It’s plain Node with zero dependencies, built on Meta’s models. A staged build: a guard removes secrets and steering, Muse Spark writes the cards and reviews its own work, Muse Wonder grades each card against the chat it cites, and a contract check reruns a malformed build. Memory is bounded: ten topics, eight cards each, fourteen words a card. The don’t-nag rule is code, not a prompt. And any agent can use it over HTTP: recall, remember, confirm. The README and docs/eval.md have the rest.
